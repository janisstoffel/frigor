# Frigor website

A small German-language Frigor concept site with an animated, configurable vest diagram. No product photographs, trackers, third-party fonts, backend, checkout or dependencies.

## Files

`dist/index.html`, `dist/style.css`, `dist/app.js`, `dist/.nojekyll` are the complete publishable site. Publish only these files, never the parent business workspace.

## Local preview

Run `python3 -m http.server 4173 --directory dist` from this directory and open http://localhost:4173.

## Behaviour

Fabric and accent colours, three patterns, front/back, custom team text and motion controls update a local SVG concept. The enquiry link opens the visitor's email program with the selected configuration. It does not send automatically or create an order. No data is stored by the app. Reduced-motion preferences are respected.

The optional WebMCP preview tool is feature-detected and edits only this local design state. Its registration/valid-invalid paths are tested through an injected harness; native browser WebMCP availability is not assumed.

## Publishing

GitHub Pages project preview; the live sales model and availability remain unconfirmed. GitHub Pages has restrictions on hosting online businesses and transaction-oriented sites. This prototype is informational and has no transactions. Reassess hosting before adding commercial ordering or launching the operational business site.
